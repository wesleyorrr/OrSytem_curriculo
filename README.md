# 📄 OR System Currículo

> **Site/aplicação web para criação e visualização de currículo** — parte do ecossistema **OR System**.

Aplicação front-end estática que permite montar e visualizar um currículo profissional diretamente no navegador, com foco em **organização, clareza visual e usabilidade** — sem necessidade de backend ou instalação.

---

## 📖 Sobre o projeto

O **OR System Currículo** é uma aplicação web desenvolvida para **criar, organizar e visualizar currículos** de forma simples e profissional. O usuário preenche suas informações e o sistema monta uma apresentação clara e bem estruturada do currículo.

Faz parte do ecossistema **OR System**, marca voltada a soluções digitais com foco em **simplicidade, performance e funcionamento offline-first**.

### 🎯 Problema que resolve

Oferecer uma ferramenta **leve e acessível** para criação de currículos, sem depender de softwares pesados, templates pagos ou plataformas complexas — ideal para quem precisa de um currículo profissional rápido e organizado.

### 👥 Público-alvo

- Profissionais em busca de recolocação no mercado
- Estudantes e recém-formados
- Pessoas que precisam de um currículo digital organizado
- Uso interno da OR System

---

## 🧠 Decisões técnicas & aprendizados

- **Vanilla JS em vez de frameworks**: escolha consciente para manter o bundle leve, o carregamento rápido e o código acessível a qualquer dev que for dar manutenção.
- **Arquitetura estática**: sem backend, o que reduz custo de hospedagem e simplifica o deploy via GitHub Pages.
- **Separação de responsabilidades**: `index.html` (estrutura), `css/` (apresentação) e `js/` (comportamento) organizados de forma clara.
- **Offline-first**: a aplicação continua funcional sem conexão após o primeiro carregamento.
- **Organização em pastas**: assets e lógica centralizados em `css/` e `js/` para facilitar manutenção e escalabilidade.
